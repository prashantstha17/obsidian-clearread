# ClearRead PDF

ClearRead PDF is an accessibility-focused PDF reading plugin for Obsidian.

It is designed to help people with:

- Dyslexia
- ADHD
- Visual stress
- Low vision
- Reading fatigue
- Cognitive overload

## Features

- Opens PDFs in an accessible reflowable reading view
- Instant font switching for all pages
- Custom font support
- Dyslexia-friendly presets
- ADHD focus mode
- Reading ruler
- Adjustable:
  - Font size
  - Line height
  - Letter spacing
  - Word spacing
  - Paragraph spacing
  - Reading width
- Background and text color controls
- Basic read-aloud support
- Local extraction cache for faster reopening

## Important

This plugin does not modify the original PDF file. It extracts text locally and renders it in a more accessible reading view.

Scanned PDFs may require OCR before they can be read properly.

## Privacy

ClearRead PDF processes PDF files locally inside Obsidian. It does not send your documents to external servers.
